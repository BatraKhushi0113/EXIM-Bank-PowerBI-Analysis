# EXIM Bank Power BI Analysis

## Project Overview

This project analyzes EXIM Bank financing data using Microsoft Power BI.

## Dataset

- 52,000+ records
- 34 columns
- Source: Excel

## Tools Used

- Microsoft Excel
- Power Query
- Power BI
- DAX

## Project Workflow

Excel → Power Query → Data Transformation → DAX → Visualization → Dashboard → Business Insights

## Dashboard Features

- Total Authorized Amount
- Total Disbursed Amount
- Total Deals
- Disbursal Rate
- Program Analysis
- Country Analysis
- Exporter State Analysis
- Fiscal Year Trends
- Interactive Slicers
